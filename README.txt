MARGRASS — сайт магазина

Запуск: распакуйте архив и откройте index.html в браузере.

index.html — главная, отзывы и каталог.
style.css — оформление и адаптация для телефона.
script.js — окна отзывов/каталога и переключение фотографий.
assets/products — фотографии товаров на белом фоне.

Каталог открывается нажатием на карточку «Электросамокаты».
В каждой карточке можно переключать фотографии миниатюрами.
Кнопка «Купить» открывает WhatsApp Хасана с текстом «Здравствуйте! Интересует [название модели]». Сообщение покупатель отправляет самостоятельно.

При обновлении существующей версии замените index.html, style.css, script.js и добавьте папку assets/products целиком.
Обновите страницу Ctrl+F5.

Детский транспорт: 10 расцветок гироскутеров, по 3 фото.
По умолчанию в каждой карточке выбран размер 6.5. Переключатель 10.5 меняет мощность, цену и выбранный вариант в сообщении WhatsApp только у своей модели.
Фотографии общие для обоих вариантов.
При обновлении замените index.html, style.css и script.js, а также добавьте assets/hoverboards целиком.

Запчасти: 4 подкатегории. При открытии по умолчанию выбраны «Покрышки»: 7 товаров, по 3 фотографии, цены и покупка через WhatsApp. Остальные подкатегории пока без товаров.
Для этого обновления замените index.html, style.css, script.js и добавьте папку assets/tires целиком.
